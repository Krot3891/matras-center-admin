# matras-center-admin — адмін-панель (Етап 0)

Окремий проєкт. Не торкається і не залежить від основного сайту
matras-center.ua (того HTML/CSS/JS, який вже існує і ще дороблятиметься).

## Статус на Етапі 0

Це каркас: сторінки й маршрутизація готові, але без реальної бізнес-логіки.

- `/login` — працює: надсилає email і пароль на `POST /auth/login` API,
  зберігає отриманий JWT у `localStorage` (ключ `adminToken`), при помилці
  показує повідомлення, після успіху веде на `/products`.
- `/products` і `/products/new` закриті: без чинного (наявного й не простроченого)
  токена перенаправляють на `/login`. Це захист інтерфейсу — доступ до даних
  все одно перевіряє сервер. Якщо сервер відповідає `401`, токен видаляється
  і відкривається `/login`.
- `/products` — реально підключена до публічного `GET /products` і
  покаже товари, якщо вони вже є в базі (на Етапі 0 їх ще нема —
  додавання товарів теж приходить на Етапі 1).
- `/products/new` — форма додавання товару є, поля відповідають
  контракту API та Prisma-схемі, але збереження (`POST /products`
  і завантаження фото в Cloudflare R2) ще не підключено.

API за замовчуванням — `https://matras-center-api.onrender.com`; змінити можна
через `VITE_API_URL`. Домен адмінки має бути в `ALLOWED_ORIGINS` на боці API,
інакше браузер заблокує запити (CORS).

## Як запустити локально

```bash
npm install
cp .env.example .env
# у .env вкажіть адресу локального API, наприклад http://localhost:4000
npm run dev
```

За замовчуванням Vite піднімає адмінку на `http://localhost:5173`.
Для роботи сторінки товарів потрібен запущений `matras-center-api`
(див. README цього проєкту) — інакше запит до `/products` впаде з
помилкою з'єднання, яку сторінка коректно покаже.

## Структура

```
src/
  main.jsx          — точка входу, BrowserRouter
  App.jsx           — маршрути: /login, /products, /products/new
  lib/api.js        — обгортка над fetch (базовий URL + токен з localStorage)
  pages/
    Login.jsx        — каркас логіну (без реальної перевірки)
    ProductsList.jsx — список товарів (реально читає GET /products)
    ProductForm.jsx  — форма товару (збереження ще не підключено)
```

## Деплой

Не виконувався і не планується в рамках Етапу 0. Коли дійде до
Етапу 1+, планується окремий субдомен `admin.matras-center.ua` —
але створення цього субдомену і будь-яка зміна DNS відбудеться
тільки після вашого окремого підтвердження.
